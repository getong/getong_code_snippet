* install hfrs

#+begin_src shell
cargo install --git https://github.com/huggingface/hf-hub.git hfrs
#+end_src


* clone huggingface repo

for example, clone repo, https://huggingface.co/datasets/Jatpeng/ue58-rag-embeddings 

#+begin_src shell
hfrs download Jatpeng/ue58-rag-embeddings --repo-type dataset
#+end_src
